# GiftLink — User Stories

## User Story Template
**As a** [type of user]
**I want** [an action]
**So that** [a benefit/value]

---

## Stories

### new
As a new user, I want to register an account so that I can start listing items.

### new
As a new user, I want to log in securely so that only I can access my profile.

### c2c
As a user, I want to list an item I no longer need so that someone else can reuse it.

### c2c
As a user, I want to browse items by category so that I can find things I need.

### c2c
As a user, I want to search for items by keyword so that I can quickly find specific things.

### c2c
As a user, I want to comment on an item so that I can ask the owner questions.

### technical debt
As a developer, I want secure JWT authentication so that user data is protected.

### technical debt
As a developer, I want concurrency-safe review operations so that data stays consistent.

### backlog
As a user, I want to edit my profile so that my information stays up to date.

### backlog
As a user, I want to see detailed item views so that I know exactly what I'm getting.
